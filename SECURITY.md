# Security and Governance Reporting

Do not encode secrets, credentials, production identifiers, or sensitive runtime transcripts in prompts, eval fixtures, or LearningRecords.

Treat any change that broadens mutation authority, external side effects, credential access, policy bypass, or runtime self-modification as a high-risk governance change requiring explicit review.

Security-sensitive findings should use Aya's approved private reporting process rather than public repository issues. This repository intentionally does not invent or publish a reporting address that has not been supplied by the organization.
